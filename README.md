# AutomotiveStore

AutomotiveStore — современная витрина для покупки и продажи автомобильных запчастей в сегментах B2B и B2C. Проект объединяет каталог, подбор по марке и модели, корзину, оформление заказа и заявки для оптовых клиентов в одном удобном интерфейсе.

## Краткое описание проекта

Сайт создан как полноценный прототип B2B/B2C-площадки для автомобильного рынка: покупатели могут быстро искать детали по категории и ключевым параметрам, а бизнес-клиенты могут оформлять оптовые заявки и получать удобный механизм заказа. Платформа построена на современной стековой архитектуре с фронтендом на React и серверной частью на Express, что позволяет быстро развивать продукт и адаптировать его под реальный бизнес-процесс.

## Что реализовано

- каталог товаров с поиском и фильтрацией;
- подбор по марке, модели и году;
- карточки товаров с краткой информацией и описанием;
- корзина с сохранением в браузере;
- оформление заказов через API;
- проверка остатков перед созданием заказа;
- формы для B2B-заявок и взаимодействия с партнёрами;
- адаптивный дизайн для мобильных устройств.

## Для кого проект

Проект подходит для автосервисов, магазинов запчастей, дилерских сетей и B2B-площадок, которые хотят быстро протестировать модель онлайн-продажи автозапчастей и оценить пользовательский опыт до подключения реальных интеграций.

## Запуск

```bash
cd server
npm install
npm run dev
```

В отдельном терминале запустите клиент:

```bash
cd client
npm install
npm run dev
```

API работает на порту `3001`, Vite проксирует `/api` к нему. SQLite-файл создаётся в `server/data/store.db`; путь можно переопределить переменной `STORE_DB_PATH`.

Production-сборка клиента: `cd client && npm run build`.

## API

- `GET /api/health` — состояние сервиса и БД.
- `GET /api/categories` — категории каталога.
- `GET /api/products?q=&category=&page=&pageSize=` — поиск и постраничная выдача товаров.
- `GET /api/products/:id` — карточка товара.
- `GET /api/fitment?make=&model=&year=` — товары из таблицы применяемости.
- `POST /api/business-leads` — сохранить заявку B2B-клиента.
- `POST /api/orders` — создать заказ в транзакции с проверкой и списанием остатков.

## Прототип

Адаптивная витрина магазина автозапчастей для розничных и B2B-клиентов. API поддерживает категории, поиск и пагинацию каталога, подбор по марке-модели-году, сохранение заявок B2B и атомарное создание заказов с проверкой остатков. Корзина и количества товаров сохраняются между перезагрузками в `localStorage`.

Каталог и применяемость заполнены демонстрационными данными. VIN-декодирование, авторизация, B2B-цены и интеграции с TecDoc, 1С/МойСклад, платежами и доставкой требуют подключения реальных сервисов. Фотографии загружаются с Unsplash.
